Samanta Mobile and Cyber Cafe

Mobile Repairing Stock Management App

A simple inventory and stock management application for mobile repairing shops.

Features

- Add new mobile spare parts
- Update product details
- Delete products
- Manage stock quantity
- Track purchase and selling prices
- Low stock alerts
- Record sales
- Sales dashboard
- Bengali + English language support

App Details

- App Name: Samanta Mobile and Cyber Cafe
- Platform: Android
- Mode: Both (Online + Offline)
- Language: Bengali + English

Purpose

To manage mobile repairing spare parts, inventory, and daily sales easily.
