SAMANTA MOBILE AND CYBER CAFE - Android project

এই ZIP-এ Android Studio project source দেওয়া হয়েছে। এটি APK নয়; APK বানাতে Android Studio-তে project খুলে Build > Build Bundle(s) / APK(s) > Build APK(s) চাপতে হবে।

প্রয়োজন:
- Android Studio (কম্পিউটার/ল্যাপটপে)
- Android SDK 35
- Gradle 8.7+ / Android Gradle Plugin 8.6.1

ধাপ:
1. ZIP Extract করুন।
2. Android Studio > Open > Samanta_Mobile_and_Cyber_Cafe ফোল্ডার নির্বাচন করুন।
3. Gradle Sync শেষ হতে দিন।
4. Build > Build Bundle(s) / APK(s) > Build APK(s)।
5. APK সাধারণত app/build/outputs/apk/debug/app-debug.apk-এ পাওয়া যাবে।

গুরুত্বপূর্ণ:
- অ্যাপটি বর্তমানে একটি offline-first starter version।
- ডেটা এই ফোনের WebView local storage-এ থাকে। App data clear/uninstall করলে ডেটা হারাতে পারে।
- নিয়মিত Report > Export Backup দিয়ে JSON backup রাখুন।
- Online sync, login, multi-user access এবং cloud backup এই starter ZIP-এ নেই।
- বিক্রির রেকর্ডে স্টক কমে যায়; ক্রয়মূল্য ধরে আনুমানিক gross profit হিসাব হয়।
